# 开环步进
优势包括低速和静止状态时具有高扭矩、边际定位误差不会累积、对启动/停止响应出色、具有成本效益且易于使用。但也存在振动噪声和失步的风险

误差
    周期性误差
        一圈内各步之间理想值与实际值间的角度误差, 会重复，但不一定累积, 某些周期性误差会随电机转角重复，因此转过完整的机械周期后，误差可能回到接近原来的状态。周期性误差不等于每一步的误差必然相互抵消，也不意味着任何情况下转一圈后误差都归零
    丢步误差
        会累积，而且不会自动消除
        假设控制器发出 1000 个脉冲，理论上电机应该走到指定位置。但如果负载太大、加速度太高，或者电机转矩不足，转子可能跟不上磁场，发生失步
    如果电机始终工作在合理的加减速曲线和负载扭矩下, 开环步进完全可能已经足够，没有必要为了纠正微小的周期性误差而加上闭环。闭环步进的价值并不是简单地消除电机固有的周期误差，而是让系统知道电机实际上走到了哪里，并在必要时采取措施。

设置
    电流
        当驱动器输出的电流增大时，步进电机的力矩也会随之增强，这使得电机能够更轻松地应对重载或高速运行等复杂工况
    静态电流
        一般有25%，50%，75%，100%等不同的划分。意思是在停止状态，驱动器给步进电机多大的电流去抱死它，持续给定。这个百分比是最大输出的百分比。在对于提升类负载，这个就有用了，静态时需要做功支撑重力。所以会调的比较大。对于水平类负载，停止状态时，转子不会被拖转的情况下，这个值一般调的就比较小。
    细分
        比如1.8度的电机，走一步旋转1.8度，一圈360度，那么需要200步。如果不细分发200个脉冲就可以走一圈。设定细分为2即一圈需要200*2为400步。保持之前频率一秒200个脉冲，这时一秒只能走半圈。
        比如1.8°步距角、4细分、螺距2mm，一圈800脉冲对应2mm移动，每个脉冲当量就是0.0025mm，定位距离除以当量就是需要的脉冲数。

# 闭环步进
设备不允许静默丢步（医疗、检测、长时间无人值守产线）
开环步进静止锁定仍需输出额定电流以维持保持力矩；闭环步进检测到位置无偏差时会降低电流输出，比开环省电, 连续运行工况下温升可下降30～50%

# 伺服
伺服驱动器内部是电流环、速度环、位置环三层嵌套, 这意味着伺服能在毫秒级内响应负载扰动
    闭环步进只有位置环一层，中间没有速度环和转矩环的精细调节，遇到变负载时响应明显迟钝
伺服电机普遍具备 2～3 倍额定转矩的短时过载能力，用于克服启动惯性、机械冲击和瞬时切削力
    这个能力是任何步进方案（含闭环）都不具备的
伺服在 3000 rpm（额定转速）以内扭矩是一条水平线
    步进从 600 rpm 开始扭矩就一路下滑，这个差异决定了两者适用的速度区间完全不同
伺服编码器17位（131072）起步，20～23位已普及
    闭环步进14位左右（16384 位置/圈）已属高配
    更高的分辨率不仅意味着更细的定位，更意味着速度环能获得更平滑的速度反馈，从而支撑更高的增益和更快的响应

# 运动控制卡
典型的 XYZ 三轴点胶平台, 控制器需要协调三个轴的运动
    假设目标位移∆x=100,∆y=50,∆z=20, 空间直线距离等于开三者的平方和即113.58, 理想直线运动时，各轴位移比例必须保持：x:y:z = 100:50:20, 也就是说，三个轴需要按照相同比例推进，而不是各自以任意速度跑到目标位置

假设plc有三个脉冲口
    方式 A：三个轴独立定位
        PLC 分别告诉 X、Y、Z 轴 “移动到你的目标位置”
        例如，三个轴分别运行定位指令。即使三个指令同时启动，也不一定沿空间直线运动，因为它们可能采用不同的加减速曲线，或者先后到达目标。
        独立定位不等于直线插补，实际路径取决于三个轴的速度与加减速协调方式
    方式 B：三轴直线插补
        PLC 或运动控制器把 (100, 50, 20) 当成一个整体目标，统一规划三个轴的运动，让三个轴按协调的轨迹同时运行
            若空间直线的运动速度为v，则三个轴的理想速度分量为：vx乘以(100/113.58), ..
        控制器需要持续协调三个轴的脉冲频率，并处理加速、减速、脉冲同步和到位判定
        如果 PLC 能执行三轴直线插补，那么它就已经具备了这项运动控制能力，不需要为了直线插补再额外购买一张运动控制卡

运动控制卡的价值是把复杂的运动计算和实时控制交给专门的运动控制硬件或系统
    情况 1：普通三轴点到点定位
        例如点胶头抬起、移动到另一个位置、下降点胶。PLC 能满足速度、精度和插补要求时，PLC 通常就够了
    情况 2：沿复杂路径连续点胶
        例如连续走直线、圆弧、曲线，同时控制点胶阀的开关或出胶量。这时，轨迹连续性、速度前瞻、拐角处理和点胶同步会变得重要，专用运动控制器可能更合适
    情况 3：PC 端直接运行复杂加工程序
        如果点胶路径由 CAD 文件、视觉系统或上位机程序实时生成，运动控制卡可以承担轨迹执行、插补和实时通信等工作，减少 PLC 自行处理复杂轨迹的开发负担

空间直线插补
    已知起点和终点，按三个轴的位移比例同步输出脉冲即可。主要难点是统一速度曲线、加减速、脉冲分配和误差控制
        这里的难度指的是从零开始编写一套可靠的轨迹生成与执行程序，而不是仅仅调用已有指令

XY平面圆弧插补
    先在 XY 平面计算圆弧，再同步控制 X、Y 轴，Z 轴保持不变。需要处理圆心、半径、起终点、顺逆时针、角度跨越和圆弧方向等问题

任意倾斜平面上的三维圆弧插补
    圆弧所在平面不与 XY、YZ、ZX 任一坐标平面重合，需要建立任意平面坐标系，将圆弧映射到平面内计算，再变换回 XYZ 坐标，并协调三个轴同步运动
        算法执行流程
            输入圆弧几何参数
            起点、终点、圆心或三点、平面方向
            建立局部坐标系
            计算平面基向量 u、v
            计算圆弧参数与速度曲线
            确定角度、方向、进给速度和加减速
            转换为 XYZ 目标位置
            实时插补与脉冲输出
            同步执行、处理误差和异常停止
        如果你有可靠的三维几何库或自己实现的向量运算，这部分数学并不算不可攻克。真正需要仔细验证的是圆弧定义是否完整、起终点是否在同一圆上、旋转方向是否正确，以及执行过程中是否保持连续的路径速度。

并不是所有运动控制卡都支持任意倾斜平面圆弧。有些产品只支持 XY、YZ、ZX 三个主平面；另一些高级控制器才支持真正的三维圆弧路径。

机器视觉与运动控制结合的典型应用有在线追踪点胶、传送带抓取、视觉引导焊接等
    相机不断检测目标的位置和形状，视觉软件不断生成或更新运动轨迹，运动控制器则实时、连续地执行这些轨迹
    整个过程可以拆成 6 步
        相机采图
            工业相机拍摄工件，得到图像。相机可能固定安装，也可能随设备运动
        视觉识别路径
            PC 上的视觉程序识别需要点胶的轮廓，得到一系列像素坐标
        像素坐标转换为机器坐标
            通过相机标定、手眼标定或平面标定，将图像中的点转换为机器的 XYZ 坐标。这里必须考虑相机与机器坐标系之间的位置和姿态关系
        生成运动路径
            视觉软件将离散点拟合成直线、圆弧或样条曲线，或者直接生成一系列短线段
        发送路径给控制卡
            控制卡接收轨迹指令或坐标点，并通过缓冲队列安排执行顺序。具体支持哪些路径类型取决于控制器
        同步运动和点胶
            控制器协调 XYZ 轴运动，并通过数字输出或其他接口控制点胶阀，使出胶时刻与实际路径位置对应

假设只有一个支持三口脉冲的plc, 按固定的轨迹运动, 不要运动控制卡, 而是在电脑上选路径配方, 编程语言例如python计算出一系列参数值, 例如各轴脉冲量加减速等等做成报文发给plc全量执行
