# 苏鬼 
【苏鬼】 《战国策·楚策三》:“苏秦之楚,三日
乃得见乎王。谈卒,辞而行。楚王曰:“寡人闻先生,
若闻古人。今先生乃不远千里而临寡人,曾不肯留,
愿闻其说’。对曰:“楚国之食贵于玉,薪贵于桂,谒
者难得见如鬼,王难得见如天帝。今令臣食玉桂,
因鬼见帝。”
战国时,苏秦游说到楚国,欲见楚王先需经谒
者通禀,而谒者难得相见像鬼一样。后用为咏谒者
或见受阻之典。

# 苏琼厚言 
【苏琼厚言】 《北史·苏琼传》:“苏琼字珍之,长
乐武强人也。除南清河太守……有百姓乙普明兄弟
争田,积年不断,各相援据,乃至百人。琼召普明
兄弟,对众人谕之曰:“天下难得者兄弟,易求者田
地。假令得田地失兄弟心,如何?”因而下泪。诸证
人莫不洒涕。普明兄弟叩头,乞外更思。分异十年,
遂还同住。”
北齐时,有乙普明兄弟争田,讼于官,长期得
不到解决。后经苏琼说服教育。感化其良知,使之
重视手足情谊,遂使兄弟和好。后因为咏官吏施
教化之典。
《幼学琼林》卷二“兄弟”:“推田相让,知延寿
之化行(见“闭阁思过”);洒泪息争,感苏琼之言
厚。”

# 素面朝天 
【素面朝天】 宋。乐史《杨太真外传》:“虢国
〔夫人)不施妆粉,自衒美艳,常素面朝天。当时杜
甫有诗云:虢国夫人承主恩,平明上马入宫门,却
嫌脂粉涴颜色、淡扫娥眉朝至尊”。”天:天子、君
主。“素面朝天”谓妇女不施脂粉,朝见帝王。

# 驷不及舌 
【驷不及舌】 《论语·颜渊》:“惜乎,夫子之说
君子也,驷(注:古时由四匹马拉的车子)不及舌。”
四匹马拉的车子也追不回说出口的话。又称
“驷马难追”。用来作为形容话一出口就无法追回,应
该守信用的典故。
明·东鲁古狂生《醉醒石》第十二回:“酒自外
人,机由内泄。悔从醒生,驷不及舌。”

# 速成而疾亡 
【松柏之茂】 《诗经·小雅·天保》:“如松柏之
茂、无不尔或承。”
“松柏茂之茂”,意谓松柏终年长绿,枝繁叶茂,
经冬而不衰败凋落。以此比喻生命力的旺盛不衰,经
得起雨雪风霜的考验。
晋·陈寿《三国志·魏书·王昶传》:“夫物速
成则疾亡,晚就则善终。朝华之革,夕而零落;松
柏之茂,隆寒不衰。”

# 耸膊成山 
【耸膊成山】 宋·刘𫗧《隋唐嘉话》:“太宗宴近
臣,戏以嘲谑,赵公无忌嘲欧阳率更曰:“耸髆成山
字,埋肩不出头,谁家麟阁上,画此一猕猴。”
比喻人的削瘦体态。
宋·陆游《衰疾》:“捉衿见肘贫无敌,耸膊成
山瘦可知。”

# 养卒说燕 
【随厮养(养卒说燕)】 《史记·张耳陈余传》:赵
王武臣为燕军所囚,十余使者去燕,均被杀。一厮
养卒主动赴燕军,游说燕将。指出张耳、陈余
‘此两人名为求赵王,实欲燕杀之,此两人分赵自
立。夫以一赵尚易燕,况以两贤王左右,而贵
杀王之罪,灭燕易矣。燕将以为然,乃归赵王,养
卒为御而归。”
秦末,赵王武臣被燕军俘虏,屡经交涉,未能
获释。后经一所养卒,独自到燕军,说服燕将,放
回赵王。后用为咏贤才之典。
唐·杜甫《过南岳入洞庭湖》诗:“才淑随厮养,
名贤隐锻炉。”
公元前209年，陈胜率领起义军攻占陈县这一战略要地后，正式称王并建立张楚政权。此时，两位在赵地颇有影响力的谋士——张耳和陈余，从藏身之处前来投奔。他们向陈胜进言，凭借在赵地广泛的人脉关系和对当地地形的熟悉，可以协助起义军夺取这片富庶之地。谨慎的陈胜虽然采纳了这个建议，却对二人心存戒备。他任命自己的老友武臣为主将，邵骚为护军，仅给张耳、陈余安排了左右校尉的次级职位，拨付三千兵马出征赵地。
武臣率军进入赵地后，立即展开声势浩大的宣传攻势。他派人在各处市集宣讲秦朝严刑峻法的暴政，颂扬陈胜起义的正义性，并号召当地豪杰共襄盛举。这番宣传在饱受秦政压迫的赵地民众中引起强烈共鸣，各地豪强纷纷率众来投，使武臣的部队在短时间内就扩充至数万之众。凭借迅速壮大的军力，武臣连续攻克十座城池，被部众尊称为武信君。在攻打范阳时，他采纳谋士蒯通提出的诱降策略，成功说服范阳令归顺，这一胜利产生了连锁反应，周边城池相继望风而降。
随着军事上的节节胜利，武臣的野心也随之膨胀。此时陈胜派出的西征主力遭遇挫败，更严重的是，他派往各地的监军滥用职权，借机铲除异己。在这种形势下，张耳、陈余抓住时机劝说武臣：陈王派出的监军肆意诛杀将领，您现在功高震主，若不早作打算，恐怕会步其后尘。在二人的怂恿下，武臣在占领邯郸后悍然自立为赵王，组建了以陈余为大将军、张耳为右丞相、邵骚为左丞相的政权班底。
消息传到陈县，陈胜勃然大怒，当即要处决武臣家眷并兴师问罪。但谋士蔡赐劝谏道：如今暴秦未灭，若再树强敌，恐非明智之举。不如暂作隐忍，承认其王位，令其西进攻秦。陈胜勉强采纳建议，将武臣家人软禁起来，同时派使者假意祝贺，要求赵王出兵伐秦。然而在张耳、陈余的谋划下，武臣采取阳奉阴违的策略，转而派韩广北取燕地，李良西攻常山，张黡进军上党，试图扩张自己的势力范围。
韩广在燕地迅速站稳脚跟后，效仿武臣自立为燕王。这个突如其来的变故让武臣尝到了当初陈胜的苦楚。盛怒之下，他亲率张耳、陈余北伐燕国，却在边境地区遭遇燕军埋伏，兵败被俘。燕国以武臣为人质，要挟赵国割让城池。张耳、陈余先后派遣十余批使者谈判，均被燕国处死。
在这个危急时刻，一名负责杂役的士兵自告奋勇前往敌营。在众人怀疑的目光中，他面见燕将，施展离间之计：张耳、陈余都是野心勃勃之人，他们表面拥立武臣，实则是为收揽人心。如今二人早想分赵自立，只是苦于时机未到。将军若杀死武臣，正合他们心意，届时他们便可名正言顺地瓜分赵国，再以复仇之名讨伐燕国。这番话说中了燕将的心事，当即释放了武臣。这个机智的士兵不仅完成了使命，还得以与赵王同乘而归，创造了死里逃生的奇迹。
与此同时，平定常山郡的李良奉命继续西进，却在石邑遭遇秦军封锁。这时他收到一封自称来自秦二世的诱降信，虽然心存疑虑，但已萌生异志。在返回邯郸请求增兵途中，李良遭遇武臣姐姐的车队。当这位醉酒的贵妇对行礼的李良不予理睬时，深感羞辱的李良在部属的煽动下，终于下定决心反叛。他先是追杀武臣之姐，继而突袭毫无防备的邯郸都城。在这场血腥的政变中，武臣和左丞相邵骚被杀，只有张耳、陈余侥幸逃脱。
武臣集团的兴亡历程，折射出秦末起义军普遍存在的历史局限。当陈胜首开称王先例后，各路义军领袖纷纷效仿，将抗秦大业抛诸脑后，沉溺于权力争夺和地方割据。这种目光短浅的权力游戏，不仅消耗了反秦力量，更埋下了内部倾轧的祸根。相比之下，刘邦能够最终取得天下，正在于他始终保持着相对清醒的政治头脑，善于团结各方力量，将主要矛头对准秦王朝。

# 岁寒三友 
【岁寒三友】 宋·林景熙《霁山集》卷四《五云
梅舍记》:“即其居累土为山,种梅百本,与乔松、修
篁为岁寒友。”
松、竹凌寒,岁晏不凋;梅花傲骨,斗雪开放:
故世称松、竹、梅为岁寒三友。又常用以比喻浊世
之中,傲岸特立的君子之交。
元·白朴《朝中措》词:“苍松隐映竹交加,千
树玉梨花(此指白梅),好个岁寒三友,更堪红白山
茶。”《孤本元明杂剧》无名氏《漁樵闲话》第四折:
“那松柏翠竹,皆比岁寒君子,到深秋之后,百花皆
谢,惟有松、竹、梅花、“岁寒三友。”

# 阳桥 
【阳桥】 《史记·孔子世家》:“孔子适
周问礼,辞去,而老子送之曰:“吾闻富贵者送人以
财,仁人者送人以言..………”
在汉·刘向《说苑·政理》:“宓于贱为单父宰,过
于阳昼,曰:“子亦有以送仆乎?”阳昼曰:“吾少也
贱,不知治民之术,有钓道二焉,请以送子。”子贱
曰:“钓道奈何?”阳昼曰:“夫投纶错饵,迎而吸之
者阳桥也,其为鱼薄而不美。若存若亡,若食若不
食者鲂也,其为鱼也博而厚味。”宓子贱曰:‘善!”
於是未至单父,冠盖迎之者交接于道。子贱曰:‘车
驱之、车驱之!夫阳昼之所谓阳桥者至矣。”于是至
单父,请其耆老尊贤者,而与之共治单父。”
古人十分重视赠言。老子对孔子所言,宓子贱
征求阳昼的留言,都表现了一句金石良言,确有兴
邦之效。后因用为仁者贵赠言之典。

# 孙晨槁席 
【孙晨蒿席】 东汉·赵岐《三辅决录》卷一:“孙
晨字元公,家贫不仕,居社城中,织箕为业。明诗
书。为郡功曹、冬月无被,有藁一束.暮卧其中,旦
收之。”(据《二酉堂丛书》本)
东汉·孙晨虽身为名士,却只在郡中作一功曹
小吏,因家境贫寒,冬天没有被褥,只有一捆干草,
夜卧其中以御寒。后用为咏贫士之典。
唐·李瀚《蒙求》诗:“孙晨藁席,原宪桑枢。”

# 琐尾流离 
[琐尾流离] 流离,鸟也。少好,长丑。始而愉乐,终以微弱。
琐尾,少时美好;流离,枭的别名。据说,枭
幼小时十分可爱,长大后却很丑恶。后世多以“琐
尾流离”比喻处境由顺利变为艰难。
蔡东藩、许盧文《民国通俗演义》第二十九回:
“哀我父老,嗟我子弟,奔走呼号,流离琐尾,泣血
椎心,无以自赎。”

# 獭祭鱼 
【獭祭鱼】《礼记·月令》(卷五):“孟春之月..
东风解冻,蛰虫始振。鱼工冰,獭祭鱼,鸿雁来。”
东汉·郑玄注:“此时鱼肥美,獭将食之,先以祭之。”
初春万物复苏,獭将捕得鱼陈列在水边,好象
祭祀一样。原指自然景象,后以“獭祭鱼”转而比
喻文人罗列典故堆砌成文。又獭祭是早春景象,因
用作咏春之典。
宋·吴炯《五总志》:“唐李商隐为文,多检阅
书史,鳞次堆积左右,时谓为‘獭祭鱼'。”
唐。独孤及《山中春思》:“獭祭春水大,人家春日长。”

# 水精如意 
【獭髓】 晋·王嘉《拾遗记》卷八:
“孙和悦邓夫人,常置膝上。和于月下舞水精如意,
误伤夫人颊,血流污桍,娇姹弥苦。自舐其疮,命
太医合药。医曰:“得白獭髓,杂玉与琥珀屑,当灭
此痕。即购致百金,能得白獭髓者,厚赏之。…
和乃命合此膏,琥珀太多……更益其妍。”
古人认为白獭的骨髓和以玉屑、琥珀屑能治愈
创伤。三国吴人孙和曾为其夫人寻觅此物。后以此
典喻咏美容药品。

# 太行失路 
【太行失路】 《战国策·魏策》:“今者臣来,见
人于大行,方北面而持其驾;告臣曰:“我欲之楚。
臣曰:“君之楚,将奚为北面?”曰:“吾马良。臣
曰:“马虽良,此非楚之路也。”曰:“吾用多。臣
曰:‘用虽多,此非楚之路也。曰:“吾御者善!”
*此数者愈善而离楚愈远耳
在大行(即太行山)前失却前进的正确方向,辕
向南而辙向北。比喻行动与目的相反,背道而驰。
阮籍《咏怀》诗:“北临太行道,失路将如何。”

# 太丘道 
【太丘道】 《后汉书·许劭传》:“劭尝到颖川,多
长者之游,唯不候陈寔。又陈蕃丧妻还葬,乡人毕
至,而劭独不往。或问其故,劭曰:‘太丘道广,广
则难周;仲举性峻,峻则少通。故不造也。
东汉许邵遍访名士,却不拜访德高望重的陈寔,
他认为道德越高的人,实则难以周备。盛名难副,故
而不拜。
唐·李端《下第上薛侍郎》诗:“终惭太丘道,
不为小生私。”此以陈寔比侍郎,谓其广引博交,
自己以一己之私相扰,甚为不安。

# 泰山妇人哭 
【泰山妇人哭】 《礼记·檀弓下》:“孔子过泰山
侧,有妇人哭于墓者而哀。……使子路问之,…
而曰:“然。昔者吾舅死于虎,吾夫又死焉,今吾子
又死焉。”夫子曰:“何为不去也?”曰:“无苛政。
夫子曰:‘小子识之,苛政猛于虎也。”
泰山下妇人三口死于虎,然而不离开此地,原
是此地无苛政的缘故。后因用作咏叹苛政或咏虎之
典。
唐·李贺《猛虎行》:“泰山之下,妇人哭声。”
此借以表现虎害。

# 谈笑行杀戮 
【谈笑行杀戮】 《隋书·杨素传》:“素多权略”
每将临寇,辄求人过失而斩之,多者百余人,少不
下十数。流血盈前,言笑自若。及其对阵,先令一
二百人赴敌,陷阵则已,如不能陷阵而还者,无问
多少,悉斩之。又令二三百人复进,还如向法。”
隋朝行军元帅杨素,带兵严厉残忍,临战之时,
常借故杀人,虽血流满地,却谈笑自若,不以为意。

# 叹丝木
 傀儡吟 刻木举丝作老翁, 鸡皮鹤发与真同, 须臾弄罢寂无事, 还似人生一梦中 
【叹丝木(三郎叹丝木)】 唐·崔令钦《教坊记》:
“至戏日,上(玄宗)亲如策曰:“好好作,莫
没三郎。”郑嵎《津阳门》诗自注:“内中皆以上为
三郎。”《全唐诗》卷一明皇帝《傀儡吟》:“刻木牵
丝作老翁,鸡皮鹤发与真同。须弄罢寂无事,还
似人生一梦中。”
“丝木”,指刻木为人形、用丝线牵引演出的木
偶戏。唐玄宗在兄弟中排行第三,故称三郎。唐明
皇曾以玩木偶戏而慨叹人生如梦,后因以“叹丝
木”为慨叹人生本幻戏,人生如梦之典。
宋·陆游《剑南诗稿》卷一《和陈鲁山十诗以
孟夏草木长绕屋树扶疎为韵》其四:“三郎老无憀
(liáo 依赖),始解叹丝木。”

# 炭兽温酒
【炭兽温酒】 《晋书·羊琇传》:“琇性豪侈,费
用无复齐限,屑炭和作兽形以温酒,洛下豪贵咸競
效之。”
晋羊琇性豪奢,他命人把炭屑和起来做成兽形,
燃后温酒,洛阳豪贵之家争相效仿。后因用为咏豪
侈的典故。
宋·陆游《剑南诗稿校注》卷六《初到荣州》:
“地炉堆兽炽石炭,瓦鼎号蚓煎秋茶。”
