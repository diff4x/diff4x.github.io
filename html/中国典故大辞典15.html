# 穷唱渭城
【穷唱渭城】 唐韦绚《刘宾客嘉话录》:“某所居
安邑里口有鬻(yù卖)饼者,早过户,未尝不闻讴
歌而当垆,兴甚早。一旦召之与语,贫窘可怜,因
与万钱,令多其本,日取饼以偿之。欣然持镪(qiàng
钱串)而去。后过其户,则寂然不闻讴歌之声,谓
其逝矣,及呼乃至,谓曰:“尔何辍歌之遽(jù急)乎?”
曰:“本流既大,心计转粗,不暇唱《渭城》矣。”
一个卖饼人每天早起歌唱,后得人资助,生意
扩大,便不再有功夫唱唐代诗人王维的《渭城曲》了。
后因以“穷唱渭城”用为典故,比喻文人在穷困时
才能写出好的诗文来。
清·王士祯《戏仿元遗山论诗绝句》:“彦回不
作中书死,更遣匆匆唱渭城。”

# 琼瑶之报
【琼瑶之报】 《诗经·卫风·木瓜》:“投我以木
瓜(注:水果),报之以琼瑶(注:美玉)。”
木瓜和琼瑶二者贵贱差别极大。“琼瑶之报”用
以为厚重报答的典故。
清・洁歌子《萤窗异草·黄灏》:“然窃计得此
以献我公,当不啻(注:不只)琼瑶之报。”

# 秋风过耳
【秋风过耳】汉·赵晔《吴越春秋·吴王寿梦
传》(卷二):“十七年,余祭卒。余昧立,四年卒,
欲授位季札,季札让,逃去,曰:“吾不受位,明矣!
昔前君有命,已附子臧之义,洁身清行,仰高履尚,
唯仁是处。富贵之于我,如秋风之过耳!”遂逃归延
陵."
春秋时吴国季札不愿接受王位,说富贵对自己
来说像秋风从耳边吹过,全不在心。后因以“秋风
过耳”比喻对事物毫不关心。
元·汪元亨《沉醉东风·归田》:“闲共渔樵讲
论时,说富贵秋风过耳。”

# 槟榔一斛
【求槟榔(槟榔一斛】 《南史·刘穆之传》:“穆
之少时家贫,诞节嗜酒食,不修拘检。好往妻兄家
乞食,多见辱,不以为耻。其妻江嗣女,甚明识,每
禁不令往。江氏后有庆会,属令勿来,穆之犹往。食
毕,求槟榔,江氏兄弟戏之曰:‘槟榔消食,君乃常
饥,何忽须此?”妻复截发市肴馔为其兄弟以饷穆之,
自此不对穆之梳沐。及穆之为丹阳尹,将召妻兄弟,
妻泣而稽颡以致谢,穆之曰:“本不匿怨,无所致优。’
及至,醉,穆之乃令厨人以金柈贮槟
榔一斛以进之。”

# 驱鳄之文
【驱鳄之文】 唐·韩愈《祭鳄鱼文》:“今与鳄鱼
约:尽三日,其率丑类南徙于海,以避天子之命吏;
三日不能,至五日,五日不能,至七曰,七日不能,
是终不肯徙也。……”
韩愈初到潮州,得悉恶溪有鳄鱼为害甚烈,便
写了这篇祭文劝其迁移。后鳄鱼西迁,潮州永无鳄
鱼为患。(事见《新唐书·韩愈传》)后遂以此用为
咏鳄之典。
清·蒲松龄《聊斋志异》卷二《遵化署狐》:
“潮州刺史,曾有驱鳄之文;汉北狂生,岂无斩狐之
剑?”

# 曲高喝寡 
【曲高和寡】 战国楚·宋玉《对楚王问》:“客有
歌于郢中者,其始曰《下里》、《巴人》,国中属而和
者数千人,其为《阳河》、《薤露》,国中属而和者数
百人;其为《阳春》、《白雪》,国中属而和者不过数
十人;引商刻羽,杂以流微,国中属而和者不过数
人而已。是其曲弥高,其和弥寡。”

# 然明改俗 
【然明改俗】 《后汉书·张奂传》:“张奂字然明,
敦煌渊泉人也。……复拜武威太守。平均徭赋,率
厉散败,常为诸郡最,河西由是而全。其俗多妖忌,
凡二月、五月产子及与父母同月生者,悉杀之。奂
示以义方,严加赏罚,风俗遂改,百姓生为立祠。”
东汉武威太守张奂字然明,他在任时,改变了
当地迷信野蛮的风俗——即二月、五月生子和与父
母同月生的,都要杀死。

# 雀呼啄粟 
【雀呼啄粟】 《论语．公冶长》皇侃义疏：“别有一书名论释曰：‘公冶长在狱六十日，卒日有雀子缘狱栅上相呼啧啧𠻘𠻘，治长含笑。吏启主：冶长笑雀语，是以解鸟语。主教问冶长：雀何所道而笑之？冶长曰：雀鸣啧啧𠻘𠻘，白莲水边，有车反覆黍粟，牡牛折角。收敛不尽，相呼往啄。狱主未信，遣人往看，果如其言。”
《北堂书钞》：“《桂阳先贤赞传》云：‘武丁能达鸟语。为郡主簿，与众人皆坐。丁偶闻雀鸣而笑曰：“东市辇粟车覆。”相呼与食。遣视果然。’”
公冶长、武丁都能听懂鸟语。后以“雀呼啄粟”为善识鸟语之典。
宋．陆游《剑南诗稿》卷七十四《雀啄粟》诗：“坡头车败雀吸粟，桑下饷来乌攫肉。”

# 蒸豚肥美 
【人乳饮㹠《世说新语．汰侈》：“武帝尝降王武子家，武子供馔并用琉璃器。……烝㹠肥美，异于常味。帝怪而问之，答曰：‘以人乳饮㹠。’帝甚不平，食未毕便去。”
晋王济生活奢侈，据说他家用人乳喂养小猪，然后上笼蒸熟来吃，其味道极美。后以此咏生活奢靡铺张之典。
宋．陆游《剑南诗稿》卷十四《对食》诗：“饮豚以人乳，万乘亦改容。”

# 任氏窖粟 
【任氏窖粟(含“陶公种秫”)】 《史记·货殖列
传》:“宜曲(地名,故址在今陕西长安县西南)任
氏之先,为督道(秦时边境县名)仓吏。秦之败也,
豪杰争取金玉,而任氏独窖仓粟。楚汉相距荥阳也,
民不得耕种,米石至万,而豪杰金玉尽归任氏,任
氏以此起富。”
秦朝末年,天下大乱,许多富豪都争相收取金
玉宝物,而宣曲任氏却大量储存粮食。后楚汉连年
争战,土地荒芜,粮价腾贵,任氏粜粮,因致大富。
后因为以食为天有远见,善经营致富之典。
《幼学琼林》卷三“饮食”:“种秫(黏高粱,可
酿酒)不种秔(音jing,同粳,不黏的稻),陶公若
以酒为命(晋陶渊明为彭泽县令,有公田三百亩,令
家人悉种秫稻,妻子固请种秔,乃使二顷五十亩种
秫,五十亩种秔。见《晋书·陶潜传》),窖粟不窨
宝,任氏则以食为天。”

# 日近长安远 
【日近长安远】 《世说新语·夙惠》:“晋明帝
(司马绍)数岁,坐元帝司马睿)膝上。有人从长
安来,元帝问洛下消息,潸然流涕。明帝问何以致
泣?具以东渡意告之,因问明帝:“汝意谓长安何如
日远?”答曰:“日远。不闻人从日边来,居然可知。”
元帝异之。明日,集群臣宴会,告以此意。更重问
之,乃答曰:‘日近。元帝失色曰:'尔何故异昨日
之言邪?”答曰:‘举目见日,不见长安。”关于此
说又见《晋书·明帝纪》。
公元三一一年(永嘉十一年),前赵刘曜攻破洛
阳,俘虏了晋怀帝,后又攻陷长安,晋愍帝被俘,于
是西晋遂亡。晋元帝司马睿,在中原南迁士族的支
持下,联合江南氏族,在南京建立了东晋政权。晋
明帝数岁时,一次长安来人与元帝闲谈,当元帝问
明帝长安和日哪个远时,明帝回答说:“日远,不闻
人从日边来,居然可知。”为彰明帝的聪明,第二天
在朝臣宴会上,再次问他这个问题时,明帝却回答
说“日近”。这使元帝大为吃惊,问他为什么改变了
昨日的答话,明帝说:“举目见日,不见长安。”
后因以“日近长安远”比喻向往帝都而不得至。
元·王实甫《西厢记》第一本第一折:“望眼连
天,日近长安远。”
清。孔尚任《桃花扇》第三十八出“沈江”:
“〔锦缠道】哭声动九原,日近长安远。加鞭,云里
指宫殿。”

# 肉食者鄙 
【肉食者鄙】《左传·庄公十年》:“曹刿请见。其
乡人曰:“肉食者谋之,又何间焉?”曰:‘肉食者
鄙,未能远谋。”肉食者:指吃肉的人,引申为高
官厚禄者。意谓身居高位,领取丰厚俸禄的人,往
往目光短浅,见识鄙陋。

# 肉鼓吹 
【肉鼓吹】 宋人《外史梼杌》(《类说》二十七
卷):五代蜀李匡远凶暴苛刻,一日不行刑,便惨然
不乐。他听到答挞之声时,便说:“此吾一部肉鼓吹。”
笞挞,指用鞭板棍棒等拷打人。鼓吹,谓鼓钲
萧笳等各种乐器的合奏,犹言今日交响乐。

# 如不胜衣 
【如不胜衣】 《荀子·非相》:“叶公子高,微小
短瘠,行若将不胜其衣然。”胜,能承受,能承担。
“如不胜衣”,意谓身体瘦弱矮小,似乎连衣服也承
担不住。形容身体虚弱。亦形容谦退的样子。《南史
·周敷传》:“敷形貌眇小,如不胜衣,胆力劲果,超
出时辈。”

# 肉屏风 
【肉阵】 五代·王仁裕《开元天宝遗事》下
《肉阵》:“杨国忠于冬月,常选婢妾肥大者,行列于
前,令遮风,盖藉人之气相暖,故谓之肉阵。”肉阵,
又称为“肉屏风”。

# 如实出己 
【如实出己】 《左传·成公三年》:“荀荦之在楚
也,郑贾人有将置诸楮中以出。既谋之,未行,而
楚人归之。贾人之晋,荀荦善视之,如实出己。贾
曰:‘吾无其功,敢有其实乎!吾小人,不可以厚诬
君子(注:诬,欺骗)。”遂适齐。”
公元前五九七年,楚庄王发兵攻郑,普军救郑,
在邲之战中,被楚军击败。荀林父(邲之战晋中军
统帅)的侄儿荀荦在此次战役中被俘。在楚人遣送
其回晋之前,郑国一商人曾设计欲救他逃离楚国。尽
管这一计划并未实行,但当他在晋见到此商人时,仍
不忘恩情,热诚相待,就如同自己真的是被商人救
出的一样。后因用为诚心感恩的典故。
宋。李清照《投翰林学士綦崇礼启》:“哀怜无
告,虽未解骖;感戴鸿恩,如真出己。”

# 如愿 
“如愿”的故事,广泛流行于晋和南北朝时。说
的是从前庐陵地方,有一个商人欧明,每逢船经过
彭泽期时,常投一点东西给湖神。一次,他又从湖
中经过,忽然湖水中现出一条大道,湖神派了车马
官员前来迎接他,要报答他的恩德。到了水府,湖
神向他要什么,欧明说只要“如愿”就够了。湖神
便把婢女“如愿”赐给他。带回家后,果然事事如
愿,不几年,欧明便成了富翁。

# 孺子可教
良愕然, 欲殴之, 为其老, 强忍, 下取履 
【孺子可教】 《史记·留侯世家》:“良尝闲从客
步游下邳圮上,有一老父,衣褐,至良所,直堕其
履圮下,顾谓良曰:“孺子,下取履!”良愕然,欲
殴之。为其老,强忍,下取履。父曰:“履我!”良
业为取覆,因长跪覆之。父以足受,笑而去。良殊
大惊,随目之。父去里所,复还,曰:“孺子可教矣。
后五日平明,与我会此。”

# 入主出奴 
【入主出奴】 唐·韩愈《原道》:“其言道德仁义
者,不入于杨(杨子,杨朱),则入于墨(墨子,墨
翟);不入于老(老子,老聃),则入于佛。入于彼,
必出于此。入者主之,出者奴之:入者附之,出者
污之。”
韩意是说,崇信一种说法,必然会排斥另一种
说法,以自己信奉者为主,以所排斥者为奴,要追
求附和某种主张,必然要否定蔑视另一种主张。后
用指不同派别的门户之见。
