# 1.5 编译器
在计算机看来，高级指令就是一堆无法理解的无用数 据。编译器是把高级语言程序翻译成计算机能理解的机器语言指令集的程序

# 3.4.3 char类型
标准ASCII码的范围是0～127，只需7位二进制数即可表示。通常，char 类型被定义为8位的存储单元，因此容纳标准ASCII码绰绰有余。许多其他系 统（如IMB PC和苹果Macs）还提供扩展ASCII码，也在8位的表示范围之 内。一般而言，C语言会保证char类型足够大，以储存系统（实现C语言的系 统）的基本字符集。

用单引号括起来的单个字符被称为字符常量

# 3.4.5 可移植类型：stdint.h和inttypes.h
C99 新增了两个头文件stdint.h和inttypes.h，以确保C语言的类 型在各系统中的功能相同。

文件中。例如，int32_t表示32位的有符号整数类型。在使用32位int的系统 中，头文件会把int32_t作为int的别名。不同的系统也可以定义相同的类型 名。例如，int为16位、long为32位的系统会把int32_t作为long的别名。然 后，使用int32_t类型编写程序，并包含stdint.h头文件时，编译器会把int或 long替换成与当前系统匹配的类型。

上面讨论的类型别名是精确宽度整数类型（exact-width integer type）的 示例。int32_t表示整数类型的宽度正好是32位。但是，计算机的底层系统可能不支持。因此，精确宽度整数类型是可选项。

C99和C11提供了第2类别名 集合。一些类型名保证所表示的类型一定是至少有指定宽度的最小整数类 140 型。这组类型集合被称为最小宽度类型（minimum width type）。例如， int_least8_t是可容纳8位有符号整数值的类型中宽度最小的类型的一个别 名。如果某系统的最小整数类型是16位，可能不会定义int8_t类型。尽管如 此，该系统仍可使用int_least8_t类型，但可能把该类型实现为16位的整数类 型。

另外，有些程序员需要系统的最大整数类型。为此，C99定义了最大的 有符号整数类型intmax_t，可储存任何有效的有符号整数值。类似地， unitmax_t表示最大的无符号整数类型。顺带一提，这些类型有可能比long long和unsigned long类型更大，因为C编译器除了实现标准规定的类型以外， 还可利用C语言实现其他类型。例如，一些编译器在标准引入 long long 类型 之前，已提前实现了该类型。

C99 和 C11 不仅提供可移植的类型名，还提供相应的输入和输出。例 如，printf()打印特定类型时要求与相应的转换说明匹配。如果要打印int32_t 类型的值，有些定义使用%d，而有些定义使用%ld，怎么办？C 标准针对这 一情况，提供了一些字符串宏（第 4 章中详细介绍）来显示可移植类型。例 如， inttypes.h头文件中定义了PRId32字符串宏，代表打印32位有符号值的合 适转换说明（如d或l）。程序清单3.6演示了一种可移植类型和相应转换说 明的用法

int32_t me32;   // me32是一个32位有符号整型变量 me32 = 45933945;
printf("me32 = %d\n", me32);
printf("me32 = %" PRId32 "\n", me32);

该程序最后一个printf()中，参数PRId32被定义在inttypes.h中的"d"替换， 因而这条语句等价于：

printf("me16 = %" "d" "\n", me16);
// 在C语言中，可以把多个连续的字符串组合成一个字符串，所以这条语 句又等价于
printf("me16 = %d\n", me16);


# 3.4.6 浮点数
2.0e20是 2后面有20个0。如果把该数加1，那么发生变化的是第21位。 要正确运算，程序至少要储存21位数字。而float类型的数字通常只能储存按 指数比例缩小或放大的6或7位有效数字。在这种情况下，计算结果一定是错 误的。另一方面，如果把2.0e20改成2.0e4，计算结果就没问题。因为2.0e4 加1只需改变第5位上的数字，float类型的精度足够进行这样的计算

C只保证了float类型前6位的精度

scanf()函数使用空白（换行符、制表符和空格）把输入分成多个字段。 在依次把转换说明和字段匹配时跳过空白, 唯一例外的是%c转换说明。根据%c，scanf()会读取每个字符，包括空白

scanf()函数所用的转换说明与printf()函数几乎相同。主要的区别是，对 于float类型和double类型，printf()都使用%f、%e、%E、%g和%G转换说 明。而scanf()只把它们用于float类型，对于double类型时要使用l修饰符, 另外l和L大小写是有区别的
%d      → int
%ld     → long
%lld    → long long
%u      → unsigned int
%lu     → unsigned long
%llu    → unsigned long long
%f      → float
%lf     → double
%Lf     → long double
%jd     → intmax_t, C 标准提供的“能够表示最大范围有符号整数”的类型
%zu     → size_t
%td     → ptrdiff_t, 主要用来表示两个指针相减得到的结果

int a[10];
int *p = &a[8];
int *q = &a[3];
ptrdiff_t d = p - q;
printf("%td\n", d); // 5


以读取%d为例, scanf()不断地读取和保存字符，直至遇到非数字字符。如果遇到一个非数字字符，它便认为读到了整数的末尾。然后， scanf()把非数字字符放回输入。这意味着程序在下一次读取输入时，首先读 到的是上一次读取丢弃的非数字字符。最后，scanf()计算已读取数字（可能 还有符号）相应的数值，并将计算后的值放入指定的变量中。

如果使用%s 转换说明，scanf()会读取除空白以外的所有字符。scanf()跳 过空白开始读取第 1 个非空白字符，并保存非空白字符直到再次遇到空白。 这意味着 scanf()根据%s 转换说明读取一个单词，即不包含空白字符的字符 串。如果使用字段宽度，scanf()在字段末尾或第1个空白字符处停止读取。 无法利用字段宽度让只有一个%s的scanf()读取多个单词。最后要注意一点： 当scanf()把字符串放进指定数组中时，它会在字符序列的末尾加上'\0'，让数 组中的内容成为一个C字符串。


// scanf()函数将其解释成：用户将输入一个数字、一个逗号，然后再输入一个数字
scanf("%d,%d", &n, &m);
// 除了%c，其他转换说明都会自动跳过待输入值前面所有的空白。因此，scanf("%d%d", &n, &m)与scanf("%d %d", &n, &m)的行为相同。


scanf()函数返回成功读取的项数。如果没有读取任何项，且需要读取一 个数字而用户却输入一个非数值字符串，scanf()便返回0。当scanf()检测 到“文件结尾”时，会返回EOF（EOF是stdio.h中定义的特殊值，通常用 #define指令把EOF定义为-1）。

# 4.4.6 printf()和scanf()的*修饰符
如果不想预先指定字段宽度，希望通过程序来指定，那么可以用*修 饰符代替字段宽度。如果转换说明是%*d，那么参数列表中应包含*和 d对应的值。这个技巧也可用于浮点值指定精度和字段宽度

#include 
int main(void)
{
    // unsigned int可简写为unsigned
    // unsigned 只能用于整数类型，它和浮点数的存储规则是两套完全不同的体系, 浮点数的 + 和 - 是通过符号位处理的，而不是像整数那样通过“有符号/无符号整数”来划分取值范围。
    unsigned width, precision;
    int number = 256;
    double weight = 242.5;
    
    printf("Enter a field width:\n");
    scanf("%d", &width);
    printf("The number is :%*d\n", width, number);

    printf("Enter a width and a precision:\n");
    scanf("%d %d", &width, &precision);
    printf("Weight = %*.*f\n", width, precision, weight);

    return 0;
}

# 函数声明
对于多个文件的程序，通常是将函数定义放到源文件（.c文件）中，将大量的函数的声明放到头文件（.h文件）中，使用函数时引入对应的头文件就可以，编译器会在链接阶段找到函数体
如果把函数的定义置于main()的文件顶部，就可以省略前置声明，因为编译器在执行到main()之前已经知道 power()的所有信息。但是，这不是C的标准风格。因为main()通常只提供整个程序的框架，最好把 main()放在所有函数定义的前面。另外，通常把函数放在其他文件中，所以前置声明必不可少。
现代的编程习惯是把程序要素分为接口部分和实现部分，例如函数原型和函数定义。
    接口部分描述了如何使用一个特性，也就是函数原型所做的；实现部分描述了具体的行为，这正是函数定义所做的。


# 进制
1位可以表示0或1，1字节8位有256（2的8次方）种可能的0、1的组合。可表示0～255的整数或一组字符
十六进制数的每一位的数恰好由4位二进制数表示。35的位组合是00110101
0x或0X前缀表示十六进制值，0前缀表示八进制
使用不同的进制数是为了方便，不会影响数被储存的方式。无论把数字写成16、020或0x10，储存该数的方式都相同，因为计算机内部都以二进制进行编码。

# char
char是一个1字节的最小的整数类型, 可以是unsigned char或signed char(用char类型表示小整数时才这样显示说明)。虽然名字叫char，但它并不是“字符类”的特殊类型
char类型实际上储存的是整数而不是字符。计算机使用数字编码来处理字符，即用特定的整数表示特定的字符。
    标准ASCII码的范围是0～127，只需7位二进制数即可表示。通常，char 类型被定义为8位的存储单元，因此容纳标准ASCII码绰绰有余
char grade = 65; 
    对于ASCII这样做没问题，但这是一种不好的编程 风格，65是int类型，但是它在char类型能表示的范围内。65是字母A对应的ASCII码，本例是把A 赋给grade。使用字符常量，而不是数字代码值, 用'A'代替65 才是较为妥当的做法，这样在任何系统中都不会出问题。
        既然字符常量一个占8位，当定义一个字符常量'FATE'，即把4个独立的8位ASCII码储存在一个32位int中。如果把这样的字符常量赋给char类型grade，只有最后8位有效。grade的值会是'E'。

## 浮点数比较 
浮点数不能直接用==比较,  浮点运算会产生微小误差, 原因是二进制浮点格式(IEE754)无法精确表示许多十进制小数
使用误差范围(epsilon)
    普通计算 1e-6
    双精度 1e-9或1e-12
    科学计算 1e-15 (double极限), 1e-19(long double极限)

#include <math.h>
#include <stdio.h>
int main(void)
{
    const double ANSWER = 3.14159;
    double response;
    printf("What is the value of pi?\n");
    scanf("%lf", &response);
    while (fabs(response - ANSWER) > 1e-9)
    {
        printf("Try again!\n");
        scanf("%lf", &response);
    }
    printf("Close enough!\n");
    return 0;
}


# 虚数,复数
虚数是为了解决平方等于负数的问题；复数是把实数和虚数合在一起的大家族。

3，-5，0，2.5，√2，π
    这些都是实数，它们能在数轴上找到位置
x^2 = -1 
    因为正正得正,负负得正, 没有任何实数能平方得到负数。
    于是定义一个新的数，让它满足：
        i^2 = -1
    这个新数叫虚数单位 i。
        它不在原来的数轴上
        我们给它开了一条虚数轴，和实数轴垂直。
    有了实数和虚数，就能“组合”起来形成复数
        a + bi
            a表示在实数方向走了多远；b表示在虚数方向走了多远。
            就像是在平面上，从原点走：右边 3（实部）, 上面 4（虚部）, 它就对应到平面上的一个点。

# scanf
输入先进入缓冲区, scanf再从缓冲区中消费数据, 而并不是从键盘实时读取字符
    按下回车后整行文本进入缓冲区, 换行符\n会被实际写入缓冲区内容

除了%c 模式（读取下一个字符），scanf()在读取输入时会跳过非空白字符前的所有空白字符(含\n)，然后一直读取字符，直至遇到空白字符或与正在读取字符不匹配的字符
    跳过空白是指上一项格式字段已经解析成功,准备解析下一项字段

%c永远读取一个字节, 不对空白做任何解析, 例如常用于菜单输入(Y/N)
    "%c" 精确读取字符,包括空格回车本身
    " %c" 跳过所有空白,常规读取一个字符

在 printf 中 %f 和 %lf 没区别，都按 double 处理
在 scanf 中 %f 和 %lf 才有区别
    %f → float *
    %lf → double *
        lf 表示 long float（历史原因命名），实际用于读取 double 类型的数据。

scanf 的返回值是一个 int 类型
    > 0	成功读取并赋值的项数（匹配成功的变量数量）
    0	没有成功读取任何项（输入格式不匹配）
    EOF (-1)	在任何输入前遇到文件结束符（EOF）或输入错误

scanf()函数允许把普通字符放在格式字符串中
    除了空格字符,其它的普通字符必须与输入字符串严格匹配。
        假设在两个转换说明中添加一个逗号： scanf("%d,%d", &n, &m);
            scanf()函数将其解释成：用户将输入一个数字、一个逗号，然后再输入一个数字。必须像这样进行输入两个整数： 88,121
scanf()中*的用法与此不同。
    把*放在%和转换字符之间时，会使得 scanf()跳过相应的输出项
        scanf("%*d %*d %d", &n);
            跳过两个整数，把第3个整数拷贝给n 在程序需要读取文件中特定列的内容时，这项跳过功能很有用。

-13.45e12# 0 
    %d
        读取3个字符（-13）并停在小数点处，小数点将被留在输入中作为下一次输入的首字符。
    %f
        读取-13.45e12，并停在#符号处，而#将被留在输入中作为下一次输入的首字符；
        然后把读取的字符序列-13.45e12转换成相应的浮点值，并储存在float类型的目标变量中。
    %s
        读取-13.45e12#，并停在空格处，空格将被留在输入中作为下一次输入的首字符；
        然后把这 10个字符的字符码储存在目标字符数组中，并在末尾加上一个空字符。
    %c
        读取并储存第1个字符

输入累加

#include <stdio.h>
int main(void)
{
    double num;
    double sum = 0;
    int status;
    status = scanf("%lf", &num);
    while (status == 1)
    {
        sum = sum + num;
        status = scanf("%lf", &num);
    }
    printf("%f\n", sum);
    return 0;
}

# 求模
取模的结果符号与被除数（左操作数）相同
    11 / 5得2，11 % 5得1 
    11 / -5得-2，11 % -5得1 
    -11 / -5得2，-11 % -5得-1 
    -11 / 5得-2，-11 % 5得-1 

C 的 % 满足公式：
    a % b = a - (a/b)*b
        -11%5： -11 - (-11/5) * 5 = -11 -(-2)*5 = -11 -(-10) = -1

C99 及之后（C11、C17、C23）保证结果一致；但在 C89/C90 中未规定符号，因此不同编译器可能给出不同结果

# 函数原型
在 ANSI C（即 C89/C90）之前，C使用的是函数声明，而不是函数原型。
    函数声明只指明了函数名和返回类型，没有指明参数类型。为了向下兼容，C现在仍然允许这样的形式

#include <stdio.h>
// void pound(); 旧式声明（K&R style），表示“参数未知”，编译器不进行参数类型检查或默认提升
void pound(int n); // 函数原型
int main(void)
{
    int times = 5;
    char ch = '!';
    float f = 6.0f;
    pound(times);
    pound(ch);
    pound(f);
    return 0;
}
void pound(int n)
{
    while (n-- > 0)
        printf("#");
    printf("\n");
}

void pound(int n);
    编译器知道 pound 接受一个 int 参数，因此：
        pound(times); → 传递 int
        pound(ch); → char 自动提升为 int
        pound(f); → float 自动转换为 int（即 6.0f → 6）
void pound();
    “我声明了一个名为 pound 的函数，但我不告诉你它的参数类型”。
    所有实参会以“默认参数提升”规则传递给函数。
        char 和 short 会提升为 int；
        float 会提升为 double。
        times → int
        ch → int
        f → double
            调用时 pound(f) 传入的是一个 double 类型，编译器不会自动转换, 因此函数内部拿到的“int n”其实是从函数栈帧里 double 的前4个字节错误解释而来的二进制内容，造成了不可预测的值。
始终为函数提供完整的原型声明。否则会导致参数类型不匹配、栈破坏或未定义行为。
