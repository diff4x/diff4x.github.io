# 医疗
## 失温
产热跟不上造成核心温度低至病态
只要核心体温维持在 >28~30℃，人仍有生存希望（即使体表冻伤严重，核心温度可被重新加热）
人体可以通过增加代谢产热（颤抖、甲状腺激素上调）、减少热量散失（皮肤血管收缩、竖毛反应、穿衣保暖） 来对抗低温

保持干燥, 热饮, 补充高热量食物, 用温热袋或暖身贴对颈部、腋窝等核心区复温(禁止四肢加热或饮酒)
保暖首重排汗，因为湿衣服贴在皮肤上会使体热散失，其散失的体热是干衣服的二十倍。
二分之一以上的体温是由头部逸失的。多戴一顶帽子和多穿一件毛衣一样的保暖。  
将干草塞衣服保暖, 甚至将塑料袋塞到衣服里面也可以起到相同的作用

轻度失温可能造成发抖与意识模糊
中度失温时发抖症状消失，意识模糊加剧
重度失温会有反常脱衣现象，患者会开始脱去衣物，行动毫无理性（包括可能尝试钻进洞里）
    人穿着湿衣服，而大脑、心脏等核心器官温度下降到一定程度，就会思维迟钝，皮肤有灼烧感，本能要脱掉衣服，而脸上带着微笑，称为死亡微笑

快速启动回温法，即将伤者浸泡在不超过35°C的温水里，并且缓慢加热到40°C，持续10分钟

低温浸透处理
    在水中托起低温浸透者身体，使其尽量保持水平, 避免竖直拉拽, 轻柔转移，避免剧烈震动, 低温状态下，心脏极度敏感，轻微刺激都可能诱发致命性心律失常
    低温浸水者体内，核心温度与四肢温度差很大, 血液大量集中在胸腔和头部
    救援时如果竖直拉起，四肢和皮肤的冷血会迅速回流到心脏和大脑，导致核心温度进一步下降，引发休克甚至心脏骤停。

滑入冰冷水塘(不挣扎 10 秒（控制住呼吸）,仰漂, 打开双手防溺水手环, 选平缓好上的地方上岸, 换上密封袋里的干衣, 贴暖身贴, 吃糖, 生火取暖, 热饮)

## 热衰竭
人体的高温“容忍区间”比低温窄得多
人体应对炎热主要依赖出汗蒸发散热和皮肤血管扩张。但这两个机制依赖外部环境条件（空气湿度、气流），在极端炎热潮湿环境下，蒸发效率会大幅下降。
当核心体温 ≥40~42℃，人体细胞代谢和蛋白质就会遭受不可逆损伤，很快出现中暑甚至热射病
出现昏倒、皮肤湿冷、恶心, 使其双脚抬高，头部稍放低，置于阴凉处。

## 腹泻
先补液, 再用药
多数旅行或户外腹泻是食物刺激, 轻度细菌污染, 肠道菌群短暂紊乱, 身体通常 1–2 天就能自己恢复。
如果过早使用洛哌丁胺, 可能会把细菌“憋”在肠道, 延长感染, 但补液永远是正确的, 可以让体力恢复更快, 改善低血容量, 减少头晕, 防止心率过快

口服补液盐
    腹泻后多喝水 / 补液, 每腹泻一次补 200–300 ml
小檗碱
    抑制多种肠道细菌, 有一定抗炎作用, 起效慢
    适用症状
        疑似细菌性腹泻 / 食物不洁吃坏肚子, 腹痛、肠鸣
洛哌丁胺
    抑制肠道蠕动, 减少腹泻次数
    适用症状
        水样腹泻, 没有血, 没发烧, 肚子咕噜但不太痛
    下面情况慎用
        发烧 > 38℃, 剧烈腹痛, 血脓便, 明显食物中毒症状（呕吐 + 发烧 + 腹泻）

## 假性止血
受伤后，血管壁反射性收缩，血流暂时减缓甚至中断。这种收缩是短暂的，过后血流恢复，可能再次大量出血。
血块、脂肪、碎骨片、压迫的组织等暂时堵住伤口。
但因为没有牢固黏附，轻微活动或血压上升就会脱落，引起再出血。
怀疑大血管损伤时，绝不能单纯依赖“出血暂时停止”。
必须及时采取可靠止血措施如压迫止血（直接压迫伤口或近心端动脉压迫点）, 加压包扎, 止血带（适用于大动脉严重出血，且需严格掌握时间）
成年人 总血量约占体重的 7%–8%
    60kg 成年人 ≈ 4.0–4.8 L
    70kg 成年人 ≈ 4.9–5.6 L
    80kg 成年人 ≈ 5.6–6.4 L
失血量小于15%（750 ml）
    一般无明显症状
失血量 15%–30%（约 750–1500 ml）
    心率呼吸加快, 皮肤苍白、湿冷，毛细血管充盈延长
失血量 30%–40%（约 1500–2000 ml）
    呼吸急促, 神志改变（烦躁、嗜睡）
失血量 >40%（>2000 ml）
    呼吸浅快或不规则, 神志丧失、失血性休克，极易死亡

## 碘伏和75酒精
碘伏杀菌速度较慢，但杀菌谱广，能持续杀菌一段时间, 刺激性弱, 可用于开放性伤口, 注意不要反复、长时间用其浸泡创面
酒精杀菌速度快，但挥发快，持续作用时间短，对部分病毒（如诺如病毒）效果较弱, 刺激性强, 不能直接用于开放性伤口

## 壳聚糖
壳聚糖只能解决止血问题, 小而浅、出血不多一般不需要壳聚糖
出血比较明显，普通加压不容易止住
直接压迫 → 壳聚糖止血敷料覆盖伤口 → 持续加压 → 外层无菌纱布/绷带固定, 这里壳聚糖和普通纱布可以配合使用
壳聚糖负责止血，外层纱布主要负责吸收渗血、保护和固定
大量出血、喷射样出血或疑似伤到较大血管, 不要把时间花在反复消毒上。立即持续强力直接压迫，必要时使用止血带

## 感染
抗生素应该针对明确或高度怀疑的细菌感染

严格来说，户外环境下很难仅凭症状“确认”细菌感染。多数情况下只能判断“是否高度怀疑”，真正确认往往需要医生检查，必要时做培养、快速抗原/PCR等检测。

你可以用一个很实用的原则：
症状越来越局限于某个部位，并且出现进行性红肿、化脓、局部发热疼痛 → 更怀疑细菌感染。
单纯发烧、黄痰、腹泻 → 不能据此判断细菌感染

抗生素对病毒感染没有作用。CDC也明确建议：不需要抗生素时，使用抗生素不会获益，反而可能造成伤害, 例如户外腹泻, 你本来就在担心饮水和腹泻，结果吃抗生素又可能造成腹泻，甚至增加脱水风险。不必要的抗生素使用会选择出耐药细菌，使以后真正需要抗生素时治疗选择变少

造成感染的细菌种类不同，抗生素需要根据感染部位、严重程度和可能的病原体选择。例如一些蜂窝织炎的治疗方案会使用阿莫西林，但另一些情况下会选择其他抗生素；如果有脓肿，还可能首先需要引流，而不是单纯吃抗生素。
阿莫西林不是户外通用的“广谱消炎药”。它属于青霉素类抗生素；即使确实是细菌感染，也可能因为耐药或病原体不同而不合适
在延迟就医风险很高的环境里，抗生素治疗的风险收益可能倾向于“治疗”，而不是完全不处理；不过仍然是“需要抗生素” 不等于 “阿莫西林一定合适”。

# 水泡
长途徒步时, 水泡本身通常不是严重伤，但它最大的危险是“越走越严重”：从一个小摩擦点，发展成破溃、感染, 你会开始改变走路姿势来躲避疼痛。例如刻意踩脚外侧、踮脚、改变步态。长距离情况下，这可能进一步造成膝盖、小腿、髋部甚至另一只脚的过度负荷。

前期：发热、发红、刺痛, 这时候还没有真正形成水泡, 这个阶段处理，往往可以直接阻止后续发展。
后期：水泡破裂, 原本的完整皮肤 + 封闭液体腔变成开放性创面, 此时砂土、汗液、袜子里的细菌都可能进入。处理重点从“防水泡”变成了清洁 → 保护创面 → 防止继续摩擦, 不要把已经松脱、完全污染的水泡皮强行留在创面上, 也不要为了处理小水泡主动把表皮去掉

水泡本质上是皮肤在“反复摩擦 + 剪切力”下，表皮和更深层组织发生相对滑动，组织液渗出形成一个小腔隙。
胶带本身可以作为一个耐摩擦层，同时减少皮肤表面的相对移动，如果胶带贴得平整，它可以让一小块皮肤整体受到保护，而不是皮肤表面不断被“搓”。
所以运动胶带不是“让摩擦消失”，而是减少皮肤受到的摩擦/剪切 + 把磨损转移到胶带上。

# 避蛇
棍子探路, 避草丛石头, 遭遇时缓慢退出而不是突然动作
蛇虽然没有耳膜，但可以通过地面震动感知猎物或天敌的活动。
    蛇对低频声音（震动）非常敏感
        猎物在附近爬行时的震动（如老鼠、小鸟在地上走动）。
        人类脚步，特别是当你在丛林或草地里行走时，蛇可以提前察觉并做出反应（通常是逃跑）。
部分蛇类（如蟒蛇、蝮蛇）可以通过“热窝”感知温血动物的热量，就像戴着红外线夜视仪
    蛇的热感应可以精准到0.003°C 的温度变化，这意味着即使是猎物呼出的热气，也能被蛇感知
蛇的分叉舌头相当于“嗅觉雷达”, 可以感知气味的方向，用于寻找猎物或逃避危险
蟒蛇通过缠绕猎物，并感知猎物心跳，确保死亡后才松口。

    临睡前先在地上敲打，捕除爬上的昆虫。
    醒来应首先仔细地察看身体周围，否则附近若的蛇和昆虫会被突然的活动惊动。

# 食物
按对其依赖的程度来排列的话人体所需要的依次是水、糖、蛋白质、维生素、微量元素
在野外时能为你提供最快最方便的能量的元素是糖, 通过蛋白质和脂肪提供则要经过更长过程, 一块巧克力肯定比一块牛肉更快地给你热量
糖类食物一般情况下是不会浪费的, 它在为人体提供了热量后多余的便成了肝糖元、肌糖元和脂肪储存了起来, 在遇险（尤其是在高寒地区）时维持生命具有重要的意义。 

“容易获得”这一条非常重要, 假如我说天上的飞鸟水里的游鱼味道很好, 在野外没东西吃了可以弄些来吃, 那就会招人骂了, 就因为它们不容易获得

昆虫是节肢动物最大的一个纲, 也是动物界中最大的一个纲, 不仅种类繁多, 而且数量惊人。因而它们是野外生存时最容易获得的可靠食物源

龙虱, “水仙”龙虱, 水陆空三栖战舰, 生活在浅水里。
    龙虱不但会游泳、会潜水(鞘翅之下有一个气囊, 能够充当潜水所用的氧气瓶), 出水还能飞
    龙虱的幼虫俗名叫做“水虎”, 以水中一切动物蛋白为食, 即使对体积庞大的小鱼、蝌蚪, 甚至青蛙, 它们也敢于主动攻击。水虎没有明显的嘴, 上颚中空, 连着口腔和食管, 它们不能咀嚼和撕咬。称霸一方的兵器, 依靠的是装有“毒液”的吸管：捕到猎物时, 水虎将毒液和消化液通过空心的上颚注入猎物体内, 肥胖的蝌蚪、小鱼受到偷袭, 用不得挣扎几下, 便不再动弹；用消化液处理后的猎物, 内脏逐渐变成暗淡的液体, 水虎就像喝软包装一样将食物吸尽, 然后将干瘪的表皮弃于水中
    龙虱夜间趋光，可以用灯光吸引
    用清水冲洗，去除泥沙和杂质, 浸泡 2-3 小时（如果有条件，可用淡盐水浸泡帮助排出肠道污物）。
    一些大型龙虱可能带有微弱毒素（主要用于捕猎），建议去除头部和胸部的唾液腺。
        用手或小刀切掉头部，再剖开胸部取出白色唾液腺。
    直接烤制：
        将龙虱用树枝穿起，明火烤 5-10 分钟，直到外壳变脆发黄。
        可直接剥壳食用肉质部分，类似吃甲壳类（如蟋蟀、蝗虫）。
    水煮：
        沸水煮 5-10 分钟，去除可能存在的寄生虫和细菌。

田螺
    田螺是一种带壳的水生软体动物, 在浅水塘、溪流、湿地均可能大量出现。由于田螺行动极其缓慢, 因此是我们在野外非常容易获得的食物源。在野外没有会做饭的田螺姑娘, 有田螺也该知足了。
    田螺的躯体分为头部、足部和脏囊三部分, 足部紧贴螺口的膜片上, 爬行时伸出来, 休息或有危险时赶紧缩回去, 拉紧膜片盖住螺口以保护自己。因此田螺足部肌肉非常发达, 为主要食用部位。
    在溪流或浅塘边, 能够较容易地捡拾到田螺。吃之前需要把田螺清洗干净, 然后敲破田螺尾部放在沸水中猛煮十几分钟杀菌及寄生生物, 倒出冷却之后剔除螺口膜片, 再将螺肉挑出来, 掐掉腹囊。螺肉再用清水淘沥一遍, 加盐再煮一会儿就可以吃了。

# 烹饪
不要用溪边的潮湿的石头垒台或当煎台

# 方位
不论是在林木遮蔽的山林中, 还是在丛草盖地的山坡上, 低头近看, 根本找不出路迹采, 只有远看, 看到几十米以外, 才能隐约地看出一条草枝微斜、草叶微倾、叶背微翻的痕迹
垂直立一根标杆,影子顶点放石子A, 10分钟后影子顶点放石子B, 与AB垂直向太阳的一端即南 
在野外迷失方向时, 立即停下来冷静回忆所走过的道路, 重新制定方向, 然后再寻找道路。最可靠的方法是“迷途知返”, 退回于原出发地。 

# 攀登
攀登岩石时应慎重地识别岩石的质量和风化程度, 确定攀登的方向和路线。 

# 涉水
仔细观察, 不要草率入水
山区河流通常水流湍急, 水温低, 河床坎坷不平。
涉渡时, 为了保持身体平衡, 应当用一根棍子支撑在水的上游方向, 或者手执重达15~20公斤石头。
集体涉渡时, 可三人或四人一排, 彼此环抱肩部, 身体最强壮的位于上游方向。
