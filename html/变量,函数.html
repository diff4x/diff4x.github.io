c是强类型语言
函数不能嵌套定义函数或匿名函数

const = 只读
可以修饰普通变量、指针、函数参数
可以保护被修饰的东西,防止意外的修改
编译器通常不为普通const常量分配存储空间,而是将它们保存在符号表 中,这使得它成为一个编译期间的常量,没有了存储与读内存的操作,使得它的效率也很高

基本用法
const int x = 10;
x = 20; // ❌ 错误，x 是只读的, 初始化后不能修改, 存储期和作用域不受影响，只是增加了只读属性

int *p;        // 普通指针
const int *p;  // 指向常量的指针, const 修饰的是指针指向的内容, 指针可改, 内容不能
int *const p;  // 常量指针, const 修饰的是指针本身, 内容可改, 指针不能
const int *const p; // 常量指针指向常量, 内容指针都不能改

指向常量的指针
const int x = 10;
const int *p = &x;
// *p = 20;           // 错误，不能通过指针修改它指向的内容
const int y = 30;
p = &y;  // 可以
常量指针
int a = 10;
int *const p = &a; // 指针本身不可改变
*p = 20;           // 可以修改指向的内容
p = &b;            // 错误，指针不可变
指向常量的常量指针
const int a = 10;
const int *const p = &a;
//*p = 20;   // 不能修改内容
//p = &b;    // 不能修改指针

const 修饰函数参数
void printArray(const int arr[], int n) {
    // arr[i] = 0; // ❌ 错误, 不能修改传入的数据
    for(int i=0; i<n; i++)
        printf("%d ", arr[i]);
}

const 修饰函数返回值，主要是为了防止调用者修改返回值指向的内容，在返回指针或引用时最有意义，返回基本类型通常意义不大。
const int foo() {
    return 10;
}
int x = foo();  // ✅ 可以赋值给变量
foo() = 20;     // ❌ 错误，不能给返回的 const 值赋值, 对于返回 基本类型（如 int、char、float）来说，加 const 几乎没有实际意义, 因为返回的是值拷贝，本身就不会影响函数内部变量。

返回指针或引用（更有意义）
const int* getValue() {
    static int x = 100;
    return &x;
}
返回的是 指向 const int 的指针, 调用者不能通过返回指针修改内容：
const int *p = getValue(); // 即使函数返回类型本身是 const int*，调用者仍然应该用相同的类型（带 const 的）来接收。
*p = 200;  // ❌ 不能修改 x
const int y = 300;
p = &y;  // ✅ 可以改变指针

C 语言区分函数靠的只是函数名（符号名）本身，与参数无关。不能有重名函数，即使参数个数或类型不同也不行。
C 编译器在编译阶段并不会区分函数参数类型去生成不同的函数名。它只根据 函数名本身 在符号表中定位函数地址。
int add(int a, int b);
double add(double a, double b);
这两个函数都会被翻译成相同的符号名：add。所以链接时就会符号冲突（duplicate symbol）。
只能用不同函数名：
int add_int(int a, int b);
double add_double(double a, double b);
或者用可变参数函数（varargs）技巧

C++ 编译器做了名字改编（name mangling）。编译器会把函数签名（参数类型、顺序等）一起编码进符号名中。因而可重载

在 C 语言中，函数名和变量名可以同名，但不能出现在同一作用域中。
全局函数可以与局部变量同名；
全局函数不能与全局变量同名。
作用域优先级：
> 局部作用域（local） > 全局作用域（global） > 外部链接（extern）
编译器在 main 函数内部看到 add 时，它优先认为这是一个局部变量，而不是全局函数。所以函数名被“遮蔽”（shadowed）。
int add(int a, int b) {
    return a + b;
}
int main() {
    int add = 10;    // ✅ 合法，局部变量 add 覆盖全局函数名
    printf("%d\n", add);  // 打印 10
    // printf("%d\n", add(3,4)); // ❌ 错误，add 现在是 int，不是函数！
    return 0;
}

指针函数
int *foo(); // 函数foo返回一个 int 型指针 (int *)。
int *getMax(int *a, int *b) {
    if (*a > *b)
        return a;   // 返回指针a
    else
        return b;   // 返回指针b
}
int main() {
    int x = 10, y = 20;
    int *p = getMax(&x, &y);
    printf("较大值是: %d\n", *p);  // 输出 20
    return 0;
}

int *wrongFunc() {
    int n = 100;
    return &n;  // ❌ n在函数结束后就被销毁
}
n 是局部变量，存在栈上，函数结束后栈空间被释放，返回它的地址会导致野指针、未定义行为。

正确做法
1. 返回全局变量的地址
int g = 42;
int *f() { return &g; }
2. 返回传入参数的地址
int *f(int *p) { return p; }
3. 返回动态分配的内存地址
int *f() {
    int *p = malloc(sizeof(int));
    *p = 42;
    return p;
}

函数指针
函数作为一段程序，在内存中也要占据部分存储空间，它也有一个起始地址, 因此可以利用一个指针指向一个函数。可以把函数名当作“地址”，用指针去保存和调用它。这个地址在符号表中是唯一的。
函数指针是“存函数地址的变量”；它可以像函数一样调用、传递、存放在数组中；是实现回调机制、模块化设计的重要工具。

int (*pf)(int, int);
pf 是一个 指向函数的指针，该函数的返回类型是 int，参数是 (int, int)
int *(*pf)(int, int); 返回类型是int *,
int add(int a, int b) {
    return a + b;
}
int main() {
    // 定义一个函数指针，指向与 add 相同类型的函数
    int (*pf)(int, int);
    pf = add;  // 函数名其实就是函数的地址
    // 通过函数指针调用
    printf("结果: %d\n", pf(3, 4));     // ✅ 可直接调用
    printf("结果: %d\n", (*pf)(3, 4));  // ✅ 等价写法
    return 0;
}

把函数作为参数传递（回调函数）, 像 qsort()、signal()、pthread_create() 这些标准库函数， 就是通过函数指针来实现“回调”的。
void execute(int (*op)(int, int), int x, int y) {
    printf("结果: %d\n", op(x, y));
}
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int main() {
    execute(add, 5, 2); // 把函数名当参数传进去
    execute(sub, 5, 2);
    return 0;
}

函数数组（类似“菜单表”）
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }
int main() {
    int (*ops[])(int, int) = {add, sub, mul};
    int a = 6, b = 3;
    for (int i = 0; i < 3; i++)
        printf("%d\n", ops[i](a, b)); // 依次调用 add、sub、mul
    return 0;
}


函数形参是指针变量
void foo(int *p) {
    *p = 100;   // 修改指针指向的内容
    p = NULL;   // 修改指针本身
}

int x = 10;
int *ptr = &x;

foo(ptr);

printf("%d\n", x);      // 100
printf("%p\n", ptr);    // ?

 1. *p = 100;
p 是函数形参，指向 x
*p = 100 → 修改 p 指向的内容
效果会影响外部变量

2. p = NULL;
这里修改的是函数内部的 p 的副本（指针本身）
外部 ptr 不受影响
ptr 仍指向 x

在 C 语言里：函数调用时，形参都是值传递。不管是基本类型还是指针类型, 都会把实参的值拷贝给形参，在函数内部操作的是形参的副本。
ptr 的值是 x 的地址（假设 0x1000）
调用 foo(ptr) 时：把 ptr 的值（0x1000）拷贝给函数形参 p, 所以 p 是 独立的指针变量，存储的值和 ptr 相同，但它是副本

如果想修改外部指针，就必须传 指向指针的指针：
void foo(int **pp) {
    *pp = NULL;  // 修改外部指针
}
int *ptr = &x;
foo(&ptr);      // 传入 ptr 的地址
pp 指向外部 ptr
*pp = NULL 直接修改外部 ptr
