使用 as 给函数指定别名
如果要导入的函数的名称太长或者可能与程序中既有的名称冲突，可指定简短而独一无二的别名
import pizza as p  
p.make_pizza(16, 'pepperoni')

使用星号导入模块中的所有函数 
from pizza import *
由于导入了每个函数，可通过名称来调用每个函数，无须使用点号, 如果模块中有函数的名称与当前项目中既有的名称相同，可能导致意想不到的结果
最佳的做法是，要么只导入需要使用的函数，要么导入整个模块并使用点号。这都能让代码更清晰，更容易阅读和理解

# 函数编写指南
给函数指定描述性名称且只使用小写字母和下划线

给每个函数写简要阐述其功能的注释

给形参指定默认值, 或使用关键字实参时，等号两边不要有空格
def function_name(parameter_0, parameter_1='default value')  function_name(value_0, parameter_1='value')

建议代码行的长度不要超过 79 个字符
如果形参很多，可在函数定义中输入左括号后按回车键，并在下一 行连按两次制表符键，从而将形参列表和只缩进一层的函数体区分开来
def function_name(  
        parameter_0, parameter_1, parameter_2,
        parameter_3, parameter_4, parameter_5): 
    function body...

如果程序或模块包含多个函数，可使用两个空行将相邻的函数分开。 这样将更容易知道前一个函数到什么地方结束，下一个函数从什么地 方开始。

  """一次模拟小狗的简单尝试"""
  def __init__(self, name, age): 
    """初始化属性 name 和 age"""

    self.age = age

    """模拟小狗收到命令时坐下"""  
    print(f"{self.name} is now sitting.")   
  def roll_over(self): 
    """模拟小狗收到命令时打滚"""  
    print(f"{self.name} rolled over!")

my_dog = Dog('Willie', 6) 
print(f"My dog's name is {my_dog.name}.") 
print(f"My dog is {my_dog.age} years old.")
my_dog.sit()
my_dog.roll_over()

资源彼此独立（数据库、浏览器、用户、Redis 等）→ 一个资源一个 fixture（推荐）。
资源本身就是一个整体（例如一个包含多个配置和对象的测试上下文）→ 返回一个对象（或 dataclass）是合理的。
返回一个大 dict 让所有测试自己取 → 可以，但通常不是 pytest 的最佳实践，因为会降低可读性，并可能创建大量用不到的资源。
