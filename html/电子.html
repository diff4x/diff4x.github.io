本杰明·富兰克林（Benjamin Franklin） 在 1740 年左右提出：电是一种“流体”，可以从物体流到另一个物体。他随意规定：
    流出电荷的地方为 正极 (+)
    流入电荷的地方为 负极 (−)
到了 19 世纪末，科学家发现：
    真正运动的载流粒子是 电子；
而电子带负电，运动方向恰好与“电流方向”相反。
但那时电学理论、电路符号、教材、工程标准都已经基于富兰克林的定义了。
所以，即使我们知道方向相反，也继续沿用原来的定义。
这就是为什么：
    电子流：负极 → 正极
    传统电流方向：正极 → 负极

# 电池
电池不是“储电子”，而是“储能量差”

电池内部有两种不同的电极材料（比如锌和铜），它们在电解液中与离子的相互作用不同：
    某些材料更容易失去电子（被氧化） → 电子势能高
    某些材料更容易吸收电子（被还原） → 电子势能低
这两个电极之间就存在一个 “电子势能差”，也就是我们常说的 电动势（EMF） 或 电压差。
这个势能差就像“高处的水会流向低处”一样，电子从高势能（负极）自然流向低势能（正极）。

电池内部有化学反应，定义正负极时并不是随便取的，而是根据化学反应中电子流动方向决定（失电子者为负极）。

电子不能穿透电解质, 电子循环只发生在外部电路
    负极失去的电子通过外电路流向正极；电池内部靠离子迁移维持电中性，从而让电子流可以持续进行。
    电子在外部循环，离子在内部循环，两者“配合”形成闭合电流回路

# 市电
市电能量的传递是“电场扰动的传播”，不是“电子的流动”

电子在导线里只是往复振动，不需要跨越整个电网来回移动，能量靠电场传播。
这种振动产生的交变电场和磁场会以接近光速传播, 能量就是沿着导线表面由电磁场传输的

50 Hz 的市电中：
    电子每秒振动 100 次（方向反转 50 次）；
    振动的幅度非常小，通常只有 微米级；
    但电场变化是整个导线“同步响应”的。
    不是远处的电子从发电厂“跑”到近处；而是电场变化传递过去，近处电子感受到电场变化被迫开始同步振动

阻性负载中, 导体内部有大量金属离子
当电子在电场作用下振动时，会不断地与这些金属离子发生碰撞, 把一部分电子的动能传递给原子；原子振动更剧烈 → 温度升高。这就是焦耳热效应

感性负载（线圈、电机线圈）中
直流电机中, 电场方向固定, 电子从负极连续流向正极。电流是连续单向的流动，产生恒定磁场。磁场方向不变，可以吸引铁芯、吸合电枢。若在电机中配合换向器（机械或电子切换电流方向），磁场方向会周期变化 → 推动转子连续旋转。

交流电机中，电子在导体内只是来回振动，平均位置几乎不变。但由于电流方向在变，磁场也随之交变（B场方向周期反转）。交变磁场与转子形成旋转磁场（通过三相电或相位差），从而驱动转子旋转。
以常见的三相交流电机为例：
每一相电流都是交流 → 电子在每相绕组中振动；
    三相电流有120°相位差；
    各绕组磁场在空间中相位错开；
    三相叠加后，结果是一个旋转磁场；
    转子（永磁体或感应转子）被这个旋转磁场“拖着走”——于是电机转动。

既然交流电让电子只是来回振动、磁场方向也在不停反转，那为什么交流电也能像直流电一样吸起铁块、做成电磁铁？
即便方向反转，在半个周期内磁场仍然存在；因此在线圈周围，磁场是“交替增强、减弱、反转”的动态磁场。
铁磁材料的磁化方向不会瞬间跟随磁场反转。
当磁场方向切换时，磁畴需要一定时间才能重新排列。这导致磁化强度滞后于电流变化。所以即使电流反向的那一瞬间，铁芯的磁化仍然部分保持原方向。
即使交流电每半周期反转，铁芯的磁化方向并不会完全跟着反转，仍然对外保持较强吸力。

因为磁场在交变、吸力在周期振荡（每秒 100 次在 50 Hz 电网中）。铁芯和铁片受到这种振动力，就会微微震动——这就是我们听到的“交流电磁铁嗡嗡声”或变压器的嗡声。

铁芯（硅钢片叠片结构）用于增强磁场（提高磁导）和减少能量损耗（降低涡流 & 磁滞损耗）

空气的磁导率几乎是 μ₀（真空值），而铁或硅钢的相对磁导率可达 几千到几万倍。

感生电动势会在铁芯内部形成闭合电流回路（称为“涡流”）。涡流在铁芯内绕圈流动；由于铁芯有电阻导致焦耳热损耗（发热）；把整块铁芯切成一片片薄片, 每片之间用绝缘漆隔开；这样涡流在每片内被“打断”；涡流回路面积变小，阻抗变大，电流大幅减小。

硅元素可以让磁化曲线“更窄”，磁畴更容易翻转从而磁滞损耗减小。

无论电子是流动还是振动：
    只要有电流（即电子运动），就会产生磁场；
    只要电流随时间变化，磁场也随之变化；
    磁场变化可以：
        对磁性材料施加力（推动转子）；
        或在邻近线圈中感应电动势（变压器原理）。

容性负载中, 电场驱动电子积累在电容板, 电荷积累形成电场

# 开关电源
开关电源是“电子流+能量调控分离”：
    外部负载的电子流是真实闭合的
    内部高频开关和变压器主要起能量传递和电压变换作用

# 发电机
发电机不依赖化学反应，靠机械能 → 磁场 → 电能转换
直流发电机的电子循环类似电池外部：负载中电子形成闭合循环
交流发电机的电子振动类似市电：电子实际位移小，能量通过电场传递

# 电容
一个电容器（capacitor）就是两块导体（极板）之间隔着一层绝缘介质（空气、陶瓷、云母、电解液等）。电子不能穿过这层介质，没有真实电子流通过电容内部。但当在两端加上电压源（比如电池或交流电）时，外电源会在两极板之间建立一个电场, 电容仍然能“传递电流信号”或“储存电能”。这是因为电子在电容的两个极板上“堆积”和“离开”的行为，形成了等效的“位移电流”。

外加电压源建立电场；电场推动电子移动；电子堆积在负极板；同时，另一极板因电子被排走，留下等量正电；两极板间的电场就是由这两层异号电荷产生的；电容就这样储存了电能。

直流情况（DC）
电子从电源的负极流到电容的负极板；在那儿堆积形成负电荷；电容另一极板的电子被排斥走，留下正电荷；当两极板之间的电场建立到平衡后，电子停止运动；电容“充满电”，电流停止。所以直流下，电子最终被阻挡在电介质外，不再流动。电容表现为断路

交流情况
交流电场方向周期性反转；于是电子在电容的两极板上来回聚散：一半周期：电子聚到左板；下一半周期：电子又被吸到右板；尽管电子不能穿过介质，
但这种同步的“充放电行为”让电流在电路中看起来连续通过。对外表现：电流仿佛“穿过了电容”，实际上只是两边电子在交替进出极板表面。这就是所谓的位移电流

感性负载，比如电动机（尤其是异步电机）；变压器；电磁线圈；镇流器等。这些设备内部都有线圈，线圈产生磁场需要无功电流。
电流相位滞后于电压；电源要提供额外电流维持磁场；虽然这些电流不做功，但占用电源容量和导线电流。
感性负载 → 电流滞后电压（“吃无功”）；
电容器 → 电流超前电压（“供无功”）。
感性负载多时，末端电压会下降； 电容器能提供超前电流，抵消压降； 所以有“稳压”效果。

# 相位
在交流电路中，电压和电流都是随时间周期性变化的量，通常用正弦波表示, 相位就是波形在时间上的偏移角度，表示电压或电流在一个周期内“走到了哪一步”。
想象一个圆形时钟盘：一个完整周期对应  或  弧度
波峰出现的位置就对应圆盘上的一个角度 → 这就是相位
相位 = 0° → 波形从零开始上升
相位 = 90° → 波峰提前1/4周期
相位 = -90° → 波峰滞后1/4周期
相位本质上是描述波形在时间上的位置的角度。

电压和电流可能不同时达到峰值
原因是电路元件不同对时间变化的响应不同：
    电阻 → 电压、电流同步 → 相位差 0°
    电感 → 电流滞后电压 → 相位 < 0
    电容 → 电流超前电压 → 相位 > 0

电压和电流相位差决定有功/无功功率：
同相 → 功率完全转化为有功
不同相 → 部分功率往返震荡 → 无功
两个波叠加时，相位决定它们干涉是加强还是抵消。

当我们说“电流超前电压90°”，这不是在说：“电流在时间上先发生，电压后发生。”
而是说：在正弦波的相位角（波形位置）上，电流的峰值比电压的峰值提前四分之一个周期。
也就是：
    电压还在上升 → 电流已经到达峰值；
    电压到达峰值时 → 电流已经降到零。
所以“超前”描述的是波形相位差，不是“动作先后顺序”。

电容内部是两块导体之间的绝缘介质，储存电场能量。
当交流电压变化时，电子需要“移动到一侧板上”或“从另一侧板离开”。
电子一旦看到电压开始变化，就立即开始充放电运动。
由于电流是电子运动的速率，而电压是电场强度（储存能量状态），
电子开始流动早于电压达到峰值，所以电流超前电压。


# 电压
电压和电流的关系
电压 = 推动力
电流 = 实际流动
元件不同 → 相位差
电阻：电压推动，电子同步流动 → 同相
电感：电压推动，电子被惯性拖慢 → 电流滞后
电容：电压推动，电子先移动储能 → 电流超前

# 电感
电感是能把电流变化转化为磁场能量的元件
电感通常是：一圈圈的导线（线圈）；有时加上铁芯或磁芯来增强磁场；
广泛用于：滤波器（抑制高频）；电源（储能、稳压）；变压器（能量耦合）；电机线圈（力的来源）。

电感是电流的“惯性”
电感不“存电荷”，而是存磁能。像一个“磁场电池”，以磁场形式暂存能量。

电感需要“时间”建立磁场；
电流变化落后电压；
所以电压波峰先出现，电流波峰后出现。所以电感中电流滞后电压90°。

电感就像一个弹簧：
电流上升时 → 弹簧被拉长 → 储能；
电流下降时 → 弹簧回弹 → 放能；
因此电流变化总被“磁场的弹性”拖住。

# 电伤人
电压本身只是“推动电子流动的潜能”，
真正造成生理效应的，是电流穿过身体时在组织中沉积的能量。

电生理效应
电信号干扰神经、肌肉，尤其心脏	心室纤颤、呼吸肌痉挛
热效应
电流产生焦耳热 	烧伤、组织炭化
电化学效应
电解体液、破坏细胞膜	局部组织坏死

心脏的节律依赖非常微弱的电信号（毫伏级）。
外部电流只要几十毫安，就能扰乱心律。
电流 (经胸)	典型生理反应
小于1 mA	几乎无感觉
1–5 mA	麻刺感、轻微震动

>5 A	立即心脏停搏、严重烧伤

电流通过导电的生物组织时：局部可瞬间达到上百度 → 烧伤；在骨骼附近（高阻）更容易积热；高压电流可能沿骨架路径内部烧伤，而皮肤表面只是一小点。
