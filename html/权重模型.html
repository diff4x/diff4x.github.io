# 权重转化为知识
本质上是不断根据前面的 Token，预测下一个 Token
    Token（词元）：AI 处理文字时使用的“最小语言单位”之一，可以看成 AI 自己的字典
预测 → 计算误差 → 反向传播 → 调整权重 → 如此循环，每生成一个 Token，都在利用数十亿甚至更多的权重进行一次巨大的数学计算
    现代大模型通过“预测下一个 Token”这种简单机制，规模足够大以后，涌现出推理、总结、翻译、编程等复杂能力
模型学习到的是一种条件概率分布，而不是一条条事实，知识分布在整个模型参数中，其中 MLP 存储大量事实知识，Attention 负责动态检索上下文信息

# 硬件算力
AI “吃 GPU”并不是因为 AI 只能在 GPU 上运行，而是因为现代 AI 的核心计算——尤其是矩阵乘法和张量运算——天然适合 GPU 的大规模并行架构
CPU 擅长“少数几个很聪明的人做复杂的事”，GPU 擅长“几千个工人同时做大量相似的简单计算”。而 AI 恰恰需要后者

# 训练过程
预训练
学习语言、知识、世界规律
SFT（指令微调）
学习“如何回答用户”
安全对齐（道德法律枷锁）
学习“哪些问题应该拒绝”
训练阶段每预测一个 Token 都会产生 Loss，用于更新权重。推理阶段不会更新权重

# 安全对齐
安全对齐阶段可能给模型大量这样的训练：
    用户：某种危险请求
    AI：我不能帮助完成这个请求。
模型就会逐渐形成：
    危险请求
    拒绝
如果没有这部分训练，模型可能更倾向于：
    用户要求什么
    尽量生成相关回答
“安全行为”不一定只来自拒绝样本，它还可能来自：
    预训练数据本身
    指令微调数据
    RLHF / DPO
    模型原本的安全对齐
    系统提示词
    推理时的安全过滤
    外部内容审核
如果从训练阶段就不加入专门的安全拒答数据，并且不进行 RLHF/DPO 等安全对齐，那么模型通常会更接近‘无审查’或‘低拒答’状态

# 无限制创作
如果把大模型看作一个超高维空间（几百亿个维度），那么每一个权重本质上就是空间里的坐标和坐标轴的角度：
    ​知识不是“存”进去的，而是“弯曲”出来的：
        预训练时，数十亿 Token 就像无数个数据点。反向传播算法（Backpropagation）不断微调这几百亿个坐标，最终将整个神经网络雕刻成一个极其复杂的高维概率曲面。
    ​推理就是“沿曲面下滑”：
        当输入一段 Token（例如“华盛顿是”），模型并不是在翻数据库，而是将这个起点放在曲面上，沿着概率最高的倾斜方向滑动，自然而然地落在了下一个概率最大的 Token（“美国首府”）上。这就是为什么它拥有“涌现”和“泛化”能力——它记住的是规律的几何结构，而不是死记硬背的文字。
在开源社区的“去限制/拒答消除”演进中，相比早期粗暴剪枝导致智商下降的 Uncensored 版本，采用 Abliterated（拒绝向量消除/正交化微调） 和 Heretic 技术的权重能够在实现接近 0%拒答率的同时，保留原模型绝大部分逻辑与语言能力。
    早期社区为了让模型不拒答，会用大量包含违禁词、无伦理的数据强行重新微调（SFT），或者粗暴删除某些安全相关的神经元。这会导致模型的通用逻辑结构被破坏，破坏了原本学到的语言规律，因此模型变得“又蠢又脏”。
​现代 Abliterated / Heretic（拒绝向量正交消除）：
    核心原理建立在几何空间上。模型做出“我不能回答”这种行为，本质上是在神经网络内部激活了一条特定的拒答向量方向，保留原模型的所有层权重，通过分析输入敏感提示词时激活的层，精准定位出那一条“拒答向量”，然后利用线性代数矩阵投影，直接将该方向上的激活强度抹平（消融）。模型的通用逻辑轴（推理、代码、语言表达）完全没动，唯独“触发拒答”的那条通路被物理阉割了。模型以为自己只是在回答一个普通的物理或数学问题，自然顺畅地输出内容，智商损失几乎为 0

from openai import OpenAI
from pathlib import Path
from tqdm import tqdm
import base64
import json
import re
import time

client = OpenAI(base_url="http://localhost:1234/v1", api_key="lm-studio")
MODEL = "Huihui-Qwen3-VL-30B-A3B-Instruct-abliterated-GGUF"
IMAGE_DIR = Path(r"D:\Dropbox\diff4x.github.io\gallery\娱乐调侃")
OUTPUT = "gallery_analysis.json"

def encode_image(path):
    with open(path, "rb") as f:
        return base64.b64encode(f.read()).decode()

def analyze(path):
    img64 = encode_image(path)
    prompt = """
你是一名互联网文化研究专家。
分析图片，不要只描述看到的内容。
请理解：
1. 图片类别：娱乐搞笑、网络梗图、政治讽刺、社会讽刺、动漫二创、新闻事件、普通图片
2. 图片表面内容：人物、物体、文字、场景。
3. 深层含义：笑点在哪里？为什么有趣？是否存在反差？是否讽刺某个人、群体、现象？是否包含网络梗？
4. 如果图片有文字：提取文字。
输出严格JSON：
{"category":"","ocr":"","subject":"","surface":"","hidden_meaning":"","humor_type":"","target":"","keywords":[]}
不要输出解释。
"""
    r = client.chat.completions.create(
        model=MODEL,
        messages=[
            {"role": "system", "content": prompt},
            {
                "role": "user",
                "content": [
                    {"type": "text", "text": "分析图片"},
                    {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{img64}"}}
                ]
            }
        ],
        temperature=0.2,
        max_tokens=2000
    )
    text = re.sub(r"```json|```", "", r.choices[0].message.content).strip()
    try:
        return json.loads(text)
    except:
        return {"error": text}

def main():
    images = [p for p in IMAGE_DIR.iterdir() if p.suffix.lower() in {".jpg", ".jpeg", ".png", ".webp", ".gif"}]
    print("图片数量:", len(images))
    result = []
    for img in tqdm(images):
        try:
            data = analyze(img)
            data["filename"] = img.name
            result.append(data)
            time.sleep(2)
        except Exception as e:
            print("错误:", img, e)
    with open(OUTPUT, "w", encoding="utf-8") as f:
        json.dump(result, f, ensure_ascii=False, indent=2)
    print("完成:", OUTPUT)

if __name__ == "__main__":
    main()

02_generate_filename.py

from openai import OpenAI
from pathlib import Path
import json
import re
import csv

client = OpenAI(base_url="http://localhost:1234/v1", api_key="lm-studio")
MODEL = "Huihui-Qwen3-30B-A3B-Instruct-2507-abliterated-GGUF"
IMAGE_DIR = Path(r"D:\Dropbox\diff4x.github.io\gallery\娱乐调侃")
ANALYSIS = "gallery_analysis.json"
LOG = "rename_log.csv"

def clean_name(name):
    return re.sub(r'[\\/:*?"<>|]', "", name).strip()[:50]

def unique(path):
    if not path.exists():
        return path
    i = 1
    while True:
        new = path.parent / f"{path.stem}_{i}{path.suffix}"
        if not new.exists():
            return new
        i += 1

def make_name(info):
    prompt = f"""
根据图片分析生成文件名。
要求：
- 中文
- 15~30字
- 一眼知道内容
- 表达核心笑点或讽刺
- 不使用标点
分析：
{json.dumps(info, ensure_ascii=False)}
只输出文件名。
"""
    r = client.chat.completions.create(
        model=MODEL,
        messages=[{"role": "user", "content": prompt}],
        temperature=0.3,
        max_tokens=60
    )
    return clean_name(r.choices[0].message.content)

def main():
    with open(ANALYSIS, encoding="utf-8") as f:
        data = json.load(f)
    logs = []
    for item in data:
        old = item["filename"]
        src = IMAGE_DIR / old
        if not src.exists():
            continue
        newname = make_name(item)
        dst = unique(IMAGE_DIR / (newname + src.suffix.lower()))
        src.rename(dst)
        logs.append([old, dst.name])
        print(old, "→", dst.name)
    with open(LOG, "w", encoding="utf-8", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["old", "new"])
        writer.writerows(logs)
    print("全部完成")

if __name__ == "__main__":
    main()


# 神经算子
工作原理
    数据收集：首先，需要收集大量的输入函数和对应的输出函数数据。这些数据可以来自于实验测量、数值模拟等。
    模型构建：选择合适的神经网络架构来构建神经算子模型。常见的架构有傅里叶神经算子（FNO）、图神经算子等。
    训练模型：使用收集到的数据对神经算子模型进行训练。在训练过程中，通过调整模型的参数，使得模型的输出尽可能地接近真实的输出。
    模型评估：使用未参与训练的数据对训练好的模型进行评估，检验模型的性能和泛化能力。
    应用模型：将训练好的模型应用到实际问题中，进行函数映射的预测和求解。

航空航天领域：在飞行器的设计和优化中，需要对流体力学方程进行求解。神经算子可以快速准确地模拟飞行器周围的气流分布，从而帮助工程师优化飞行器的外形，提高飞行性能。
能源领域：在石油开采、电力系统等方面，需要对复杂的物理过程进行建模和预测。神经算子可以通过学习历史数据，准确地预测油藏的产量、电力系统的负荷等，为能源的合理开发和利用提供支持。
生物医学领域：在药物研发、生物成像等方面，需要对生物分子的行为和特性进行研究。神经算子可以通过处理生物分子的结构和动力学数据，帮助科学家更好地理解生物分子的功能，从而加速药物研发的进程。
